# Module 1: Microsoft Excel Core Basics

This folder contains my foundational Excel exercises covering data manipulation, logic, and visualization.

## 📊 Concepts Practiced
* **Text Cleansing:** `LEFT`, `RIGHT`, `MID`, `UPPER`, `LOWER`, `TRIM`, `LEN`, `SUBSTITUTE`.
* **Date Functions:** `NOW`, `TODAY`, working day calculations.
* **Formulas & Layouts:** `ROUND`, `ISNUMBER`, `ISTEXT`, `TRANSPOSE`, `SUMPRODUCT`.
* **Data Visualization:** Building Column, Bar, Line, Pie, Area, and Scatter charts.
